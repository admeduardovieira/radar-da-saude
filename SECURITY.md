# Segurança e privacidade

Não criar commits com tokens, credenciais, dados privados de pacientes ou documentos protegidos. Se encontrar uma exposição, interrompa a publicação e comunique ao responsável pelo projeto por canal privado antes de abrir uma issue pública.

As informações institucionais de agentes públicos devem ser minimizadas ao necessário para a finalidade cívica e sempre provenientes de fontes legítimas. O registro financeiro precisa respeitar o nível de publicidade de cada documento.
